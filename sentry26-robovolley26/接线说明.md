# 接线说明（雷达导航 + VOFA 调试版）

> 适用：RoboVolley 工程，底盘 STM32F407IGHx
> 引脚均以本工程 CubeMX 固件配置为准（与网上常见 C 板例程可能不同，勿照抄别人的接线图）
> 文档更新：2026-11-16

## 1. 雷达（NUC）↔ 底盘

默认使用 **CAN2，1 Mbit/s**。将 NUC 的 CAN 适配器接到 C 板 CAN2 的 CAN_H / CAN_L，同名相接，并连接信号参考地。总线两端各保留一个 120 Ω 终端电阻。固件的 CAN2_RX / CAN2_TX 分别为 PB5 / PB6，它们是 MCU 到收发器的逻辑引脚。

如需切回 USART6，将 `APP/robot_config.h` 中的 `NUC_USE_CAN` 改为 `0` 并重新编译，然后按下表接线。

| NUC 侧 | 底盘侧 | 引脚 | 说明 |
|---|---|---|---|
| 串口 TX | USART6_RX | **PG9** | 雷达数据进底盘 |
| 串口 RX | USART6_TX | **PG14** | 预留（底盘当前不回传） |
| GND | GND | — | **必须共地** |

- 电平 3.3V TTL。NUC 是台 x86 小主机，若用 USB-TTL 小板引出串口，选 3.3V 电平档。
- UART 采用 115200、8N1。两种链路都由雷达周期发送 `0x0402`（含零速帧）。UPC 下 200 ms 未收到有效底盘指令会将速度目标置零并关闭小陀螺，收到新有效指令后可自动恢复。详见 [NUC 雷达通信协议](NUC雷达通信协议.md)。

## 2. VOFA 无线透传（正点原子无线烧录器）↔ 底盘 —— USART1，115200

| 无线烧录器 | 底盘侧 | 引脚 | 说明 |
|---|---|---|---|
| TX | USART1_RX | **PB7** | 仅查看曲线时可悬空 |
| RX | USART1_TX | **PA9** | 底盘 VOFA 数据发给烧录器 |
| GND | GND | — | **必须共地** |

- 烧录器自身用 USB 供电即可；上位机软件中切到**串口透传模式**，波特率 115200。
- 只看 VOFA 曲线时，接烧录器 RX → C 板 PA9 和 GND。当前 CubeMX 将 PA10 分配给 TIM1_CH3。
- 上位机 VOFA+ 选 JustFloat 协议及烧录器的 COM 口。7 个通道依次为 NUC 最近一次有效指令的 `vx`、`vy`、生效的小陀螺标志、滤波后的 `vx`、`vy`、`vw` 和 VOFA 链路心跳。NUC 超时时，前两路仍显示最近一次有效指令，应看滤波输出是否向零收敛。

## 3. 遥控器接收机（DBUS）↔ 底盘 —— USART3，100000

| 接收机 | 底盘侧 | 引脚 | 说明 |
|---|---|---|---|
| DBUS 信号线 | USART3_RX | **PC11** | 遥控数据 |
| 5V / GND | 板子 5V / GND | — | 接收机供电（5V） |

- 波特率固定 100000（固件内设好，无需配置）。
- 拨杆 S1 上档（值 1）为遥控，中档（值 3）为雷达控制（UPC），下档（值 2）为停机。下档将速度目标置零，底盘经速度滤波和 PID 减速。

## 4. 底盘电机 M3508 ×3 ↔ 电调 ↔ CAN1

| 连接 | 引脚 | 说明 |
|---|---|---|
| CAN1_RX | **PD0** | 到 CAN 收发器 → 电调总线 |
| CAN1_TX | **PD1** | 同上 |

- 每个 M3508 配一个电调（C610/C620），三个电调的 CAN_H/CAN_L 并联到 CAN1 总线，总线两端各并一个 120Ω 终端电阻。
- 电调电源接 24V 电池；电机三相线按电调对应相序接。
- 本工程 CAN1 的 MCU 引脚是 **PD0/PD1**，用于底盘电机。CAN2 的 MCU 引脚是 **PB5/PB6**，默认用于 NUC。

## 5. 电源与共地

- C 板 24V 供电（XT30），电调共用电池。
- **所有信号链路（雷达、烧录器、接收机）必须与底盘共地**，否则通信异常。
- 信号电平一律 3.3V TTL；5V 只用于给接收机/蓝牙类模块供电，不要直接灌进 3.3V 引脚。

## 6. 上电检查顺序

1. 接好雷达和共地后上电，在 VOFA 查看第 7 通道是否翻转。这个心跳只表示 VOFA 链路工作。
2. S1 保持在下档，雷达发 `(vx=+0.5, vy=0)`，确认 VOFA 第 1 通道更新到 0.5。
3. 切到 UPC，以小速度确认实车坐标轴，再按协议文档第 7 节验证超时和恢复。
4. 联调时由操作手掌握遥控器。上档且摇杆回中可人工接管，下档可进入停机模式。
