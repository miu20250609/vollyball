# 接线说明（雷达导航 + VOFA 调试版）

> 适用：RoboVolley 工程，底盘 STM32F407IGHx
> 引脚均以本工程 CubeMX 固件配置为准（与网上常见 C 板例程可能不同，勿照抄别人的接线图）
> 版本：2026-11-02

## 1. 雷达（NUC）↔ 底盘 —— USART6，115200

| NUC 侧 | 底盘侧 | 引脚 | 说明 |
|---|---|---|---|
| 串口 TX | USART6_RX | **PG9** | 雷达数据进底盘 |
| 串口 RX | USART6_TX | **PG14** | 预留（底盘当前不回传） |
| GND | GND | — | **必须共地** |

- 电平 3.3V TTL。NUC 是台 x86 小主机，若用 USB-TTL 小板引出串口，选 3.3V 电平档。
- 协议见《NUC雷达通信协议.md》，雷达侧周期发帧（含零速帧）。

## 2. VOFA 无线透传（正点原子无线烧录器）↔ 底盘 —— USART1，115200

| 无线烧录器 | 底盘侧 | 引脚 | 说明 |
|---|---|---|---|
| TX | USART1_RX | **PA10** | 烧录器发给底盘（本工程暂无下行数据，可只接 TX+GND） |
| RX | USART1_TX | **PA9** | 底盘 VOFA 数据发给烧录器 |
| GND | GND | — | **必须共地** |

- 烧录器自身用 USB 供电即可；上位机软件中切到**串口透传模式**，波特率 115200。
- 上位机 VOFA+：JustFloat 协议，选烧录器配对出的 COM 口，7 个通道，最后一个为链路心跳（闪烁=通）。

## 3. 遥控器接收机（DBUS）↔ 底盘 —— USART3，100000

| 接收机 | 底盘侧 | 引脚 | 说明 |
|---|---|---|---|
| DBUS 信号线 | USART3_RX | **PC11** | 遥控数据 |
| 5V / GND | 板子 5V / GND | — | 接收机供电（5V） |

- 波特率固定 100000（固件内设好，无需配置）。
- 拨杆 s1 中档 = 雷达控制模式（UPC），其他档位 = 遥控接管（急停用）。

## 4. 底盘电机 M3508 ×3 ↔ 电调 ↔ CAN1

| 连接 | 引脚 | 说明 |
|---|---|---|
| CAN1_RX | **PD0** | 到 CAN 收发器 → 电调总线 |
| CAN1_TX | **PD1** | 同上 |

- 每个 M3508 配一个电调（C610/C620），三个电调的 CAN_H/CAN_L 并联到 CAN1 总线，总线两端各并一个 120Ω 终端电阻。
- 电调电源接 24V 电池；电机三相线按电调对应相序接。
- ⚠️ 本工程 CAN1 用的是 **PD0/PD1**（很多 C 板例程是 PB8/PB9），CAN2 用 **PB5/PB6**。这是固件配置，接线必须跟固件走；CAN2 暂未启用（排球机构禁用中）。

## 5. 电源与共地

- C 板 24V 供电（XT30），电调共用电池。
- **所有信号链路（雷达、烧录器、接收机）必须与底盘共地**，否则通信异常。
- 信号电平一律 3.3V TTL；5V 只用于给接收机/蓝牙类模块供电，不要直接灌进 3.3V 引脚。

## 6. 上电检查顺序

1. 先接好雷达 + 共地，底盘上电，VOFA 看链路心跳通道是否闪烁（不依赖雷达，底盘单独上电就应闪烁）；
2. 雷达发 (vx=+0.5, vy=0)，看 VOFA 第 1 通道是否为 0.5；
3. 确认坐标系方向（见协议文档 §5 实测方法）；
4. 全程遥控器 s1 备在 RC 档，异常随时切回急停。
